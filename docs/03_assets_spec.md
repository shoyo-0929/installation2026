# アセット仕様（背景/ガイド） v0.1

## 1. 目的
- 12種類の水彩背景（菩提心）と、各背景に紐づく3種類のガイド線を、フロントで確実に扱える形に整理する。

## 2. 必要アセット一覧
- 背景：12枚（必須）
- ガイド線：背景ごとに3種 → 合計36枚（必須）
- （任意）サムネイル：背景12枚（一覧表示用）

## 3. 推奨フォーマット
### 3.1 背景
- 推奨：`webp`（軽量）
- 代替：`png`（画質優先）
- 透過：通常不要（背景なので）

### 3.2 ガイド線
- 推奨：**SVG（ベクター）**（拡大縮小でも綺麗）
- 代替：`png`（制作が簡単）

> 点線の多角形ガイドはSVGに非常に向く。将来「パスそのものを判定/スナップ」にも利用しやすい。

## 4. サイズ基準
- 基準：Base 1024×1024（キャンバス生成解像度に合わせる）
- UI表示はスケールで調整

## 5. 命名規則（例）
### 5.1 背景
- `bg_{bodhicittaId}.webp`
  - 例：`bg_01.webp` ... `bg_12.webp`

### 5.2 ガイド線（3種）
- `guide_{bodhicittaId}_{variant}.svg`
  - variant：`01|02|03`
  - 例：`guide_01_01.svg`, `guide_01_02.svg`, `guide_01_03.svg`

### 5.3 サムネ（任意）
- `thumb_bg_{bodhicittaId}.webp`
  - 例：`thumb_bg_01.webp`

## 6. 表示位置・余白
- 背景とガイド線は同じ座標系で完全に重なること（中心ズレ禁止）
- 1024のキャンバスに対して「ぴったり全域」か「一定余白を含めたデザイン」かを統一
  - 推奨：全域（0,0〜1024,1024）

## 7. バージョン管理（推奨）
- アセット差し替えに備え、`assetsVersion` をJSONで持つ（例：`assets_manifest.json`）
- フロントは `bodhicittaId` と `variant` から参照するだけにして、ファイル名変更の影響を最小化

## 8. チェック項目
- 背景12枚：色味・明度・コントラストが文字可読性を損ねないか
- ガイド線：端末縮小時も点線が潰れないか（SVG推奨理由）
- 透過/アンチエイリアス：ガイド線の端が汚くならないか
