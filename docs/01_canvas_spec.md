# キャンバス仕様書 v0.1

## 1. 目的
- 正方形キャンバス上に「背景（水彩）＋ガイド線＋文章＋ユーザー軌跡」を表示し、ユーザーが自由形状で切り抜き可能にする。
- 切り抜き結果を画像（透過PNG想定）として生成し、API/Storageへ送信できる状態にする。
- 「文章が消えない」ことを最優先（Safe Zone/合成ルールで担保）。

## 2. 用語
- **Canvas**：画面上の正方形表示領域（表示サイズは端末に応じて可変）
- **Base Canvas（内部解像度）**：生成処理に使う基準解像度（例：1024×1024）
- **User Path**：ユーザーのなぞり点列（x,y,t）
- **User Mask**：User Pathから作る塗り領域（閉領域化して塗る）
- **Safe Zone**：文章が必ず残る領域（文章外接矩形＋余白）
- **Final Mask**：最終的に残す領域 `Union(UserMask, SafeZone)`
- **Guide**：切り抜きの補助線（3種切替）

## 3. レイヤー構成（必須）
描画と生成でレイヤーを分離する。

1) 背景（菩提心・水彩画像）  
2) ガイド線（点線図形）  
3) ユーザー軌跡（描画中プレビュー）  
4) 文章（常に最前面）  
5) マスク（内部処理用・通常非表示）

## 4. 座標系・サイズ
- UI表示はレスポンシブ（端末幅に合わせて縮放）
- 内部生成は **Base Canvas** を基準（暫定：1024×1024）
- UI座標 → Base座標へ変換して点列を保存する（倍率でぶれないように）

## 5. 文章表示仕様（暫定）
- 配置：キャンバス中央（固定）
- フォント：後で確定（Safe Zone計算のため、フォントサイズ/行数/最大文字数を早期に固定推奨）
- 改行：許可（最大行数を設定）

## 6. Safe Zone（文章が消えない仕様）
### 6.1 Safe Zone定義（暫定）
- `SafeZone = TextBoundingBox + padding`
- padding（暫定）：上下左右 40px（Base 1024基準）

### 6.2 合成ルール（確定案）
- `FinalMask = Union(UserMask, SafeZone)`
- 出力生成は以下：
  1. 背景を FinalMask で切り抜き（透過以外を残す）
  2. 文章は常に上レイヤーとして合成（UserMaskの影響を受けない）

## 7. User Path取得（Pointer Events）
- Pointer Eventsで統一（touch/mouse/pen）
- CSS：`touch-action: none;`（スクロール/ズーム干渉を抑制）
- 点列：`[{x, y, t}]` を一定間隔で追加  
  - 追加条件例：前点からの距離が一定以上（例：2〜4px相当）

## 8. 未閉領域の扱い（ユーザー要望：厳密にしない）
### 8.1 基本方針
- ユーザーが閉じきらなくても、システム側で自然に閉領域を作る。

### 8.2 クローズ判定（スナップ）
- 始点 `S` と終点 `E` の距離 `d = |S-E|`
- `d <= closeThreshold` なら「意図的に閉じた」とみなして **EをSへスナップ**して閉じる
- `d > closeThreshold` でも、領域化のために **直線でSへ接続して閉じる（自動クローズ）**

**closeThreshold（暫定）**
- Base 1024基準：`min(40px, CanvasSize * 0.04)` のように相対＋上限で設定
- 実装は端末DPRも考慮して調整

## 9. 自己交差の扱い（厳密にしない）
### 9.1 塗りルール
- Canvasの `fill("evenodd")` 相当（even-odd）を採用（暫定）  
  → 自己交差でも「それなりに」期待通りに抜けやすい

### 9.2 形状が破綻するケースの軽減（推奨）
- 点列を間引く（距離閾値）
- 必要なら簡易のパス簡略化（Ramer–Douglas–Peucker等）を導入
- 最大点数を設ける（例：2,000点）超過時は間引きを強める

## 10. ガイド線
- 背景（菩提心）ごとに 3種類
- 右下ボタンで `1 → 2 → 3 → 1`
- 実装形式は `03_assets_spec.md` に従う

## 11. 出力画像生成（暫定）
- フォーマット：PNG（透過）
- サイズ：Base Canvas（暫定 1024×1024）
- 生成手順（概略）
  1. `UserMask` を生成（閉領域・even-odd）
  2. `FinalMask = Union(UserMask, SafeZone)` を生成
  3. 背景に FinalMask を適用（クリップ/合成）
  4. 文章を合成
  5. `toBlob("image/png")` 等でバイナリ化

## 12. パフォーマンス・メモリ（最低限）
- 生成用Canvasは必要時のみ確保（常時巨大Canvasを保持しない）
- iOS Safariのメモリに注意：解像度を上げすぎない（まず1024）
- 描画中プレビューは軽量化（毎フレーム全再描画しない/レイヤー分離）
