# 音仕様（Web Audio） v0.1

## 1. 目的
- 指の動き（なぞり）に合わせて音のエフェクトを鳴らし、操作の気持ちよさを上げる。
- iOS Safariの制約を踏まえ、確実に鳴る設計にする。

## 2. 前提（iOS制約）
- iOS Safariはユーザー操作がないと音が鳴らない（自動再生不可）。
- 対応：最初の「開始」押下で `AudioContext.resume()` を実行する。

## 3. 採用技術
- Web Audio API（推奨）
- 音源は制作チームから提供（wav/mp3）
  - 推奨：短いSE（0.1〜0.5s）を複数

## 4. 仕様（暫定）
### 4.1 音のトリガー
- `pointermove` のたびに鳴らすのではなく、**一定距離ごと**に発音する（連打/負荷/破綻回避）。
- 例：移動距離が `stepDistance` を超えたら1回鳴らす。

**stepDistance（暫定）**
- Base 1024基準：12〜20px相当（調整）

### 4.2 速度連動
- 指速度 `v`（px/秒）に応じて以下を変化させる（範囲を固定してクリップする）
  - 音量（gain）
  - ピッチ（playbackRate）
  - フィルター（lowpassのcutoff）※任意

### 4.3 同時発音数（ポリフォニー）
- 同時発音の上限を設ける（例：4）
- 超過時は「古い発音を止める」または「新規発音を抑制」

## 5. アセット要件（制作チームへの依頼事項）
- ファイル形式：wav推奨（編集・デコード向き）
- サンプリング：44.1kHz/48kHzどちらでも可
- 長さ：短め（0.1〜0.5s）
- 音量：正規化しすぎず、実装側でgain調整できる余地を残す

## 6. 実装メモ
- 初回ロードで `fetch → decodeAudioData` し、AudioBufferをキャッシュ
- 発音は AudioBufferSourceNode を都度生成（軽量）
- モバイルでの遅延が出る場合：ファイル数/サイズを見直す
