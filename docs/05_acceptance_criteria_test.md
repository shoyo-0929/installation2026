# 受け入れ基準＆テスト観点 v0.1

## 1. 受け入れ基準（Acceptance Criteria）
### 1.1 基本フロー
- [ ] 会員番号入力 → 投稿文章を取得し表示できる（失敗時は明確なエラーと再試行）
- [ ] 菩提心を選択してキャンバスに遷移できる
- [ ] キャンバスで切り抜き操作 → 完了 → 画像生成 → 共有URL表示まで到達できる

### 1.2 文章保護（最重要）
- [ ] どんな切り抜きでも文章が消えない（Safe Zone/合成ルールで担保）
- [ ] 文章がキャンバス外に出ない（中央固定の前提）

### 1.3 未閉/自己交差（厳密にしない方針）
- [ ] 終点が始点に近い場合は自然に閉じる（スナップ）
- [ ] 終点が遠い場合でもシステムが自動クローズして画像生成できる
- [ ] 自己交差しても極端に破綻せず「それなりに」期待通りのマスクになる（even-odd等）

### 1.4 10秒再開
- [ ] 指を離しても10秒以内に規定条件で再開できる
- [ ] 10秒超過でリセットされる
- [ ] 近傍判定NGの場合は最初からになる

### 1.5 ガイド線
- [ ] 右下ボタンで3種が順番に切替できる
- [ ] 背景ごとに対応するガイドが表示される

### 1.6 音
- [ ] 開始ボタン等のユーザー操作後、iOS Safariでも音が鳴る
- [ ] なぞり中、一定距離ごとに音が鳴り、連打で破綻しない

---

## 2. テスト観点
### 2.1 端末・ブラウザ
- iOS Safari（最新/1世代前）
- Android Chrome（最新/1世代前）
- iPad Safari（最新/1世代前）

### 2.2 操作系
- pointercancel（通知/画面回転/スクロール介入）でも破綻しない
- 画面回転時の座標ズレ（可能なら回転は固定/回転時はリセットなど方針を決める）
- 戻る/クリア/完了の押し間違い耐性（誤操作時の挙動が一貫）

### 2.3 パフォーマンス
- 長くなぞっても重くならない（点列上限/間引きが効いている）
- 画像生成がタイムアウト/クラッシュしない（1024基準）

### 2.4 表示品質
- 文章の可読性（背景が明るすぎ/暗すぎ問題）
- ガイド線が潰れない（縮小時、点線が見える）
